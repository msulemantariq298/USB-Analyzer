USB Attack Vector Matrix & Mitigations

T1091 / T1200

Replication Through Removable Media

Adversaries move into air-gapped networks via USB storage volumes carrying droppers or modified autorun scripts.

Defense: Automatic real-time volume hashing, autorun heuristic quarantine, and strict corporate whitelisting.
T1059.001

BadUSB Keystroke Injection

Microcontrollers masquerade as standard human interface devices to inject rapid PowerShell commands.

Defense: Keystroke cadence heuristic detector (flagging >15 cps bursts) and immediate port isolation.
T1036.001

Hardware Masquerading & Spoofing

Attacker flashes malicious USB device with known vendor VID/PID to mimic authorized enterprise peripherals.

Defense: Multi-factor hardware fingerprinting combining VID, PID, bus class, and unique hardware serial validation.
T1562.001

Disabling Security Tools

Malicious peripherals attempt to disrupt endpoint protection services or terminate monitor daemons.

Defense: Out-of-band WMI polling heartbeat and persistent policy daemon with zero-trust fallbacks.
